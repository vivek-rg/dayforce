# Frontend

React, TypeScript and Vite, with no router or chart library. Screens are in `src/features/`, shared code is in `src/shared/`, and routes are hash-based. The browser calls relative `/api` only and keeps the bearer token in `sessionStorage`, so a refresh stays signed in and closing the tab ends it.

`src/shared/api-types.ts` is generated by `npm run contracts`. Never edit it by hand.

```sh
npm run test --workspace frontend
```

```sh
npm run build
```
