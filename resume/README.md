# Team resumes

Each of eight members supplies their own PDF named `firstname_lastname_resume.pdf`, lowercase with underscores (example: `alex_rao_resume.pdf`). Do not add sample or invented resumes.

**Privacy gate:** a public repository makes personal contacts/education/work history public. Obtain each member's consent and follow organizer handling requirements before publishing. Resume PDFs are **not ignored** and can be staged normally with `git add resume/firstname_lastname_resume.pdf` after review. No force-add is needed. Review the staged file and never publish another member's details without their permission. Never upload identity scans or private reference data.

Track 8 checks eight genuine files, legibility, naming and consent at P13; the foundation contains zero resumes.
